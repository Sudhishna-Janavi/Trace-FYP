# Trace — deployment dependencies.
#
# PyTorch is deliberately absent. The encoder runs as an ONNX graph under
# onnxruntime instead, which was verified to produce identical predictions on
# every one of 1,500 held-out transactions (scripts/verify_onnx.py) while
# reducing peak resident memory from 401 MB to 292 MB. That difference is what
# makes a 512 MB instance viable, and it removes roughly a gigabyte of wheels
# from the build.
#
# Training still uses PyTorch; see requirements-training.txt. Nothing in the
# deployed application does.
